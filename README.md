# EduConnect · Digital Education Platform

A learning app interface where students study topics, take quizzes and track their progress.

## Features

- Onboarding and sign-in screens
- Study materials by subject (Math, Science, English)
- Quizzes, bookmarks, a progress tracker and a leaderboard
- Language selector with English, Hindi and Telugu translations
- Built-in study music player
- Progress and settings saved in the browser (localStorage)

> Content comes from sample data in `src/data/mockData.ts`; there is no backend.

## Tech stack

React · TypeScript · Vite · Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```
